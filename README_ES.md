Un **Spot Arbitrage Screener** es un software de arbitraje de criptomonedas diseñado para supervisar continuamente los mercados spot de múltiples exchanges y detectar oportunidades reales de arbitraje entre ellos.

A diferencia de muchos bots de trading tradicionales, cuyo objetivo principal es ejecutar órdenes automáticamente, este software está diseñado principalmente como un **scanner de arbitraje en tiempo real**. Analiza libros de órdenes, compara precios ejecutables, verifica la liquidez disponible, revisa las redes de retiro y depósito y calcula el beneficio estimado para ayudarte a identificar oportunidades antes de que desaparezcan.

Actualmente, el software es compatible con **Binance** y **Bybit**, permitiendo monitorizar cientos de pares de trading de forma simultánea desde una única interfaz.

# ¿Por Qué Es un Screener y No Solo un Bot de Trading?

Muchos bots de trading prometen automatizar completamente las operaciones.

Sin embargo, en el arbitraje entre exchanges el mayor desafío no suele ser ejecutar una orden, sino **descubrir una oportunidad rentable antes que el resto del mercado**.

Las diferencias de precio entre Binance y Bybit suelen durar solo unos segundos o minutos.

Durante ese tiempo es necesario comprobar rápidamente:

* En qué exchange comprar.
* En cuál vender.
* Si existe suficiente liquidez.
* Si las redes de retiro y depósito son compatibles.
* Cuánto costará la transferencia.
* Cuál es el beneficio estimado.
* Cuánto tiempo lleva activa la oportunidad.

Realizar todas estas comprobaciones manualmente para cientos de pares resulta prácticamente imposible.

Spot Arbitrage Screener realiza este trabajo automáticamente en tiempo real y muestra únicamente las oportunidades que cumplen con los filtros y condiciones definidos por el usuario.

En lugar de sustituir al operador, el software le proporciona toda la información necesaria para tomar decisiones mucho más rápido.

Su objetivo principal es responder una única pregunta:

> **¿Dónde está la siguiente oportunidad real de arbitraje entre Binance y Bybit?**

# Compra Automática (Auto-Buy) Opcional

La función principal de Spot Arbitrage Screener es encontrar oportunidades reales de arbitraje entre Binance y Bybit lo antes posible.

Para los operadores que desean reaccionar todavía más rápido, el software incorpora una función opcional de **Compra Automática (Auto-Buy)**.

Cuando esta función está habilitada, la aplicación supervisa continuamente todos los pares configurados.

Si una oportunidad alcanza el porcentaje mínimo de beneficio definido por el usuario, el software puede abrir automáticamente una orden de compra en el exchange donde el activo tenga el precio más bajo.

Esto permite reducir considerablemente el tiempo de reacción frente a la ejecución manual, algo especialmente importante cuando las oportunidades duran pocos segundos.

La Compra Automática es totalmente opcional y puede activarse o desactivarse en cualquier momento.

>
> La versión estándar del software está diseñada principalmente como un Spot Arbitrage Screener con opción de compra automática.
>
> La transferencia de activos entre exchanges y la venta final permanecen bajo el control del operador para que cada oportunidad pueda revisarse antes de completar el ciclo de arbitraje.

# ¿Por Qué Es Importante el Tiempo de Vida de una Oportunidad?

No todas las oportunidades de arbitraje tienen la misma calidad.

Una diferencia de precio que desaparece en pocos segundos puede resultar imposible de aprovechar.

En cambio, una oportunidad que permanece activa durante más tiempo suele ofrecer mayores probabilidades de ejecución.

Por este motivo, Spot Arbitrage Screener calcula continuamente el **Tiempo de Vida de la Oportunidad (Opportunity Lifetime)**.

Además del beneficio estimado, el software muestra cuánto tiempo lleva activa cada oportunidad.

Esta información ayuda al operador a distinguir entre:

* movimientos momentáneos del mercado;
* diferencias temporales de precio;
* oportunidades más estables.

Muchos traders profesionales utilizan este indicador junto con el porcentaje de beneficio antes de decidir si ejecutar una operación.

# Filtros Avanzados

Cada operador trabaja con una estrategia diferente.

Algunos solo negocian Bitcoin y Ethereum.

Otros supervisan cientos de criptomonedas al mismo tiempo.

Por ello, Spot Arbitrage Screener incorpora un completo sistema de filtros.

## Lista Blanca

Permite supervisar únicamente las criptomonedas seleccionadas.

Ejemplos:

* BTC
* ETH
* SOL
* XRP

---

## Lista Negra

Permite excluir activos que no forman parte de tu estrategia.

Resulta especialmente útil para evitar:

* tokens con poca liquidez;
* memecoins;
* activos recién listados;
* mercados excesivamente volátiles.

---

## Beneficio Mínimo

Muestra únicamente oportunidades cuyo beneficio supera el porcentaje configurado.

Esto ayuda a eliminar operaciones poco rentables que podrían quedar anuladas por las comisiones de transferencia.

---

## Depósito Máximo

Permite definir el capital máximo utilizado para calcular las oportunidades disponibles.

El software estima el volumen realmente ejecutable según el importe configurado.

---

## Tamaño Máximo por Operación

Limita la cantidad máxima utilizada en cada oportunidad de arbitraje.

Esta función facilita una mejor gestión del riesgo.

---

## Umbral para Compra Automática

El porcentaje utilizado para activar la Compra Automática puede configurarse de forma independiente.

De esta manera es posible visualizar oportunidades con beneficios pequeños mientras la ejecución automática solo se activa cuando aparece una oportunidad realmente interesante.
